# Data Pipeline: Sparrow Loader

Этот модуль отвечает за сбор пользовательских снимков и метаданных с сайта переписи воробьёв.

Источник данных:
- основной сайт: https://vorobey.nbud.ru/
- карта с точками наблюдений: https://map.vorobey.nbud.ru/

Пайплайн используется для подготовки датасета, который затем размечается и применяется для обучения модели детекции воробьёв.

## Что делает пайплайн

`sparrow_loader` выполняет рекурсивный обход карты переписи и сохраняет:

- метаданные точек наблюдений;
- ссылки на фотографии;
- изображения из пользовательских наблюдений;
- CSV/JSON-файлы для последующей обработки.

Основная сложность состоит в том, что карта отдаёт данные кластерами. При большом масштабе одна точка на карте может соответствовать группе наблюдений. Поэтому пайплайн рекурсивно дробит географическую область (`bbox`) и увеличивает `zoom`, чтобы раскрывать кластеры и получать отдельные точки.

## Результат работы

После запуска в выходной папке создаются:

```text
output_dir/
├── metadata.csv
├── metadata.json
├── sparrow_fetch.log
└── images/
    ├── image_1.jpg
    ├── image_2.jpg
    └── ...
```

## Пример запуска
Из папки data_pipeline:

```bash
python -m sparrow_loader \
  --output-dir ../data/sparrow__out \
  --max-zoom 18 \
  --max-depth 22 \
  --min-bbox-size 0.001
```

Для тестового запуска с ограничением по числу точек:

```bash
python -m sparrow_loader \
  --output-dir ../data/test_out \
  --max-points 100 \
  --max-downloads 100
```

Для отдельного региона:

```bash
python -m sparrow_loader \
  --output-dir ../data/moscow_out \
  --region "Москва" \
  --max-zoom 18 \
  --max-depth 22
```

## Основные параметры
|Параметр	| Назначение|
|---|---|
|--output-dir | Куда сохранять метаданные и изображения|
--bbox | Географическая область обхода: min_lat,max_lat,min_lon,max_lon
--region | Фильтр по региону, как в интерфейсе карты
--seasons | ID сезонов переписи через запятую
--initial-zoom | Начальный zoom карты
--max-zoom | Максимальный zoom при раскрытии кластеров
--max-depth | Максимальная глубина рекурсивного деления bbox
--min-bbox-size | Минимальный размер ячейки bbox
--max-points | Ограничение числа точек для тестового запуска
--max-downloads | Ограничение числа скачанных изображений


## Практическая стратегия сбора
Для полного сбора данных по плотным регионам рекомендуется:

+ Начать с умеренных параметров, например --max-zoom 18 --max-depth 18.
+ Проверить sparrow_fetch.log на предупреждения о нераскрытых кластерах.
+ Если кластеры остались, увеличить --max-depth до 22 или выше.
+ При необходимости уменьшить --min-bbox-size.
+ Для экономии времени дожимать отдельные плотные регионы через --region или --bbox.

## Ограничения
+ Сайт может отдавать данные кластерами, поэтому один проход не всегда гарантирует полный сбор всех точек.
+ Сайт ограничивает доступ при подключении с VPN.

## Роль в проекте
Этот пайплайн является частью ML/R&D-контура проекта:

```text
сайт переписи → парсинг фото и метаданных → разметка → обучение YOLO → анализ ошибок → веб-сервис
```

Собранные изображения используются для разметки классов:

+ ignore_zone
+ other_bird
+ sparrow
